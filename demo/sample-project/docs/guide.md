# User Guide

## Installation

```bash
cargo install sample-project
```

## Usage

Run the project:

```bash
sample-project
```

## Configuration

Create a `config.toml` file:

```toml
name = "my-app"
version = "1.0.0"
debug = false
```

## Troubleshooting

If you encounter issues, check the logs in `~/.local/share/sample-project/`.
